3. Known Limitations / Data Gaps

  • No header row in CSV — column names are inferred from value patterns. Need to confirm column dictionary with Thermo Fisher data steward.
  • Carrier / Route fields missing — page 7 uses Origin Plant × Destination Country proxy. To enable real carrier analysis, add carrier_code, route_id, transit_mode, lane to the source pull.
  • Miss reason / root cause field missing — cannot do automatic root cause classification. Manual classification or NLP on memo fields needed.
  • Dollar at Risk computed from c34 — assumed to be order line amount in USD. If c34 is local currency, FX conversion is required.
  • AMER baseline 19.85% is a fixed reference — if a rolling or segmented baseline is preferred, expose it via a parameter table.
  • Promise date logic — uses c43 as the promise date and c49 as the actual ship date. Confirm with business which of c42–c50 is the contractual commitment vs internal target.
  • Sample data used in this mockup — 5,000 synthetic OTTP rows generated to mirror the real distributions observed in the first 500K rows of UCSD_OTTP_Data_Pull.csv.
